## 每日解析额度

- 后台按结算日（`DAILY_QUOTA`，默认 30 行）扣减成功解析行数，当日成功数绝不超过额度。
- 本日超额处理只能定一种：`candidate`（多出来的行进次日候补匣）或 `fail`（当场失败并写「额度已满」，先填满当日剩余额度）。定下后当日不可更改。
- 候补匣跨日后需手动点「继续」，按新日额度重算，不会自动开析。
- 末位额度并发争抢只留先到（SQLite 上用 `QuotaDay.used` 的 CAS 原子更新）。
- 额度列表 `/quota/` 展示额度、今日已析、候补数、处理名；详情页旁注记录候补顺序与抢额失败。

环境变量：`DAILY_QUOTA`、`OVERAGE_DEFAULT`（candidate/fail）、`QUOTA_TODAY`（ISO 日期，测试钉死结算日）。
